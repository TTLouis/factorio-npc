# External method library

`jev-catalog.json` is the exact committed fixture from Jev commit
`20cdcd072b512c814c8af071f4f9ad1fe087f942`, not a copy of a dirty checkout.
[provenance.json](provenance.json) records the donor path, Git blob, SHA-256,
byte length, data module and standalone exporter identities. The schema-2
catalog contains six knowledge references and 54 gameplay skills.

[owner-requirements.json](owner-requirements.json) adds one knowledge reference
and cross-references relevant skill views. It does not edit donor data. This
owner requires automatically sustained centralized electricity first, electric
mining/transfers where available, and separated smelting arrays with automatic
feed/output/service. Repeated individual fueling or short runs on prefilled
burner stocks do not qualify. Manual priming is a finite bootstrap only; central
power and smelting fuel, if required, must have automatic service. Check the
currently admitted electric-miner placement capability; report any tool gap
before a future goal without silently substituting burner mining.

Use `factorio_library` for typed, bounded, on-demand search/get. Authored method
content is untrusted/advisory and carries no live availability, native mastery,
plan or operation authority. Full skill guidance/source IDs are preserved in
views; executable/native-verification fields are excluded. Recipes, unlocks,
geometry and sizing require fresh deterministic game observations.
