# Proposed next red-science trial — owner review required

This is a plan for **one** fresh delegated CLI-proxy trial after the reviewed
Run V fixes pass local integration checks. The owner requested this plan before
approval. No new live trial is authorized or started by this document. The
broader E2E goal remains paused.

## Release and preflight

Freeze the clean Jev integration candidate and build its local server image
without changing `.env`. Independently check actual deployed runtime/prompt,
release manifest and compiled-mod bytes, both role serializers, configured
Sol 6.1 planner/Luna executor and existing Jev. CLI proxy remains its own
upstream-provider profile, independent of endpoint transport. Restore the
existing loopback forwarding helper only if the configured route needs it.
Never print keys or private endpoints.

After owner approval, use a new isolated Compose project and cold world with
empty inventory, zero humans, idle native queues and a new goal. Verify the
readonly model catalog before the single objective. Give the original starter
once: eight iron plates, one burner drill, one furnace, pistol and ten ammo.

## Construction and supervision

- **Proposed construction cap: 60 wall minutes**, rather than 45. **Proposed
  reserve floor: 40% weekly remaining for this one trial only.** Both require
  owner approval; all provider, output, admission, observation and recovery
  limits stay unchanged. No reset credit or automatic second trial.
- The parent handles release verification, integration and topology review.
  A bounded subagent owns observation, the run ledger, safe stop/save/down and
  compact milestone reports. No corrective gameplay, prompts, extra items,
  teleporting or operator repairs. Observe at roughly 90-second intervals.
- Keep existing automatic recovery for model/transport pauses. A pause message
  containing “exhausted” is insufficient stop authority. The runner and external
  supervisor consume the same tested classifier. Before an automatic supervisor
  stop, reread native/trace data, read canonical state last, and repeat terminal
  classification. The owner can always explicitly stop the trial.
- Stop on canonical structural/user-decision blockage, nonresumable guard,
  current scoped automatic-resume exhaustion, an uncleared recoverable pause
  for ten minutes, fatal failure, actor/goal/human/speed invariant change,
  construction cap or approved usage floor. No manual resume or blind retry.

Verify milestones from native evidence: iron/copper smelting; actual connected
steam power; automatic coal/iron/copper mining, fuel and smelting; gear and red
assemblers with physical belts/inserters; newly produced science. Report
equipment held, structures placed and working connections separately. The
existing water-only correction offers bounded observed exploration centers;
the model must choose movement and rediscover water/placement after arrival.
It does not grant a destination, reachability, legal placement or extra reads.

## Unattended acceptance test

Only after canonical construction completion, native readiness and parent
review of a hash-bound topology packet may measurement begin. Pause AI gameplay
mutations, require empty native task/crafting queues, remove enemies and disable
expansion for measurement. Run **five wall minutes at 2×**, require at least ten
game minutes, **ten NEW red packs and at least one pack per game minute**.
Verify upstream production, physical ore/item/fuel routes and real steam power
throughout. Hand-fed stock or manual crafting cannot prove this factory.

Finish with same-goal paired cancellation/operator pause, cleared intake and
native idle. Require a fresh completed Factorio checkpoint, full ZIP CRC and
same-root complete native save files before down. Preserve traces, snapshots,
wire, save and hashes; stop only the isolated stack and any trial-owned tunnel.
Report success or the exact boundary, then leave the broader goal paused.
No release, remote push, deployment or follow-up trial is included.
